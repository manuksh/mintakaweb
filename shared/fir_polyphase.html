Architecture — Polyphase FIR Data Path

Stage 1Input & phase select
→
Stage 2Current + delayed taps
→
Stage 3Per-phase MAC
→
Stage 4Scale & output
y[n] = Σk=0T−1 hphase,k · x[n−k]

The phase input selects one coefficient bank for each accepted sample. Tap 0 uses the current input sample and the remaining taps use the registered sample history. This makes the block suitable for interpolation, decimation and filter-bank structures.
