Architecture — Complex Multiply and Scale

Stage 1Four signed products
→
Stage 2Real / imaginary sum
→
Stage 3Fixed-point scale
→
Stage 4Overflow & saturation
(are + j·aim) · (bre + j·bim) = (arebre − aimbim) + j(arebim + aimbre)

Four signed products form the complex result. An arithmetic right shift restores the selected fixed-point scale; each I/Q output is independently checked and optionally clamped.

Parameters

ParameterDefaultDescription
kDataWidth16Signed input width for every I and Q component.
kOutWidth16Signed output width for the real and imaginary results.
kFracBitsToDrop15Product fractional bits removed to restore the output Q-format.
kEnableSaturation1'b1Clamps each component to the signed output range on overflow.
